# 壁纸目录（不纳入版本控制）

本目录用于存放主站背景壁纸，**二进制图片不入库**（`.gitignore` 已忽略本目录内的图片文件），因此本仓库以本说明文件作为占位。

## 使用说明

将壁纸图片放入本目录，命名规则（对应「2026-08-06 壁纸自动轮换方案」）：

- 日期命名（定点启用）：`YYYY-MM-DD-任意名.jpg`，例：`2026-08-01-极光.jpg` 表示 2026-08-01 启用
- 普通命名（循环池）：`loop-01.jpg`，日期文件全部过期后进入 3 天循环轮换
- 支持扩展名：`.jpg` `.jpeg` `.png` `.webp`

## 本地兜底壁纸

`static/wallpaper.jpg`（页面回退路径）同样不入库，需手动放置。后端 `/wallpaper` 接口上线前，页面会回退使用该文件。

## 部署须知

生产环境部署时，请将壁纸文件单独拷贝到服务器对应目录（不入库，勿依赖 git clone）。
